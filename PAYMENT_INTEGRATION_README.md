## 📋 Процесс оплаты

1. **Пользователь** использует команду `/pay 100`
2. **Бот** показывает адрес кошелька для оплаты
3. **Пользователь** отправляет USDT на указанный адрес
4. **Пользователь** нажимает "✅ Проверить оплату"
5. **Система** проверяет платеж через Payment Bot API
6. **При подтверждении** средства зачисляются на баланс
