## 🔄 КАК РАБОТАЕТ

1. **Пользователь** указывает свой кошелек: `/wallet TUserWallet123456789`
2. **Пользователь** хочет пополнить: `/pay`
3. **Бот** запрашивает актуальный кошелек через API
4. **Пользователь** переводит средства на полученный адрес
5. **Пользователь** нажимает "Проверить платеж"
6. **Бот** автоматически проверяет и зачисляет средства
