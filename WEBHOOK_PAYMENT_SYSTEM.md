# 🔗 Система webhook для обработки платежей

## ✅ Что реализовано

### 1. Webhook сервер
- **Порт**: 8001
- **Endpoint**: `http://localhost:8001/`
- **Health check**: `http://localhost:8001/health`

### 2. Автоматическая обработка платежей
- Платежная система уведомляет бота о получении платежа
- Бот автоматически создает вклад на полученную сумму
- Не требуется ручная проверка платежей

### 3. Отслеживание ожидаемых платежей
- Регистрация ожидаемых платежей по кошельку пользователя
- Автоматическое сопоставление входящих платежей с пользователями

## 🔄 Как работает новая система

### 1. Пользователь вводит кошелек
```

📅 Тип депозита: 30 дней (30% прибыль)

Введите ваш USDT кошелек (TRC20):
• Адрес должен начинаться с 'T'
• Длина не менее 34 символов
```

### 2. Показываются инструкции по оплате
```
💰 ВНЕСЕНИЕ ВКЛАДА

📋 Инструкция по оплате:
1️⃣ Отправьте ЛЮБУЮ сумму USDT на указанный кошелек
2️⃣ Используйте ваш кошелек как отправитель
3️⃣ Система автоматически определит полученную сумму

🏦 Кошелек для оплаты:
`TWJ5wQPnJTk2keYXjEgf19i17ZzACBY4Mx`

👤 Ваш кошелек (отправитель):
`TYourWallet1234567890123456789012345`

📅 Тип вклада: 30 Days
🆔 ID отслеживания: usdt_123456789_1696600000

💡 Вы можете отправить любую сумму от 50 USDT
⚠️ ВАЖНО: 
• Используйте указанный кошелек получателя
• Отправляйте с вашего кошелька TYourWallet1234567890123456789012345
• Система автоматически определит полученную сумму
```

### 3. Пользователь отправляет USDT
- Пользователь отправляет любую сумму на `TWJ5wQPnJTk2keYXjEgf19i17ZzACBY4Mx`
- Платежная система получает USDT

### 4. Платежная система уведомляет бота
```json
POST http://localhost:8001/
{
  "user_wallet": "TYourWallet1234567890123456789012345",
  "amount": 150.75,
  "transaction_hash": "abc123...",
  "confirmed_at": "2025-10-06T15:30:00Z",
  "currency": "USDT"
}
```

### 5. Бот автоматически обрабатывает платеж
- Находит пользователя по кошельку
- Создает вклад на полученную сумму
- Зачисляет средства на баланс
- Удаляет из ожидаемых платежей

## 🔧 Технические детали

### Webhook сервер
```python
class WebhookServer:
    def __init__(self, bot_instance, host='localhost', port=8001):
        self.bot = bot_instance
        self.host = host
        self.port = port
```

### Обработка webhook
```python
def process_payment_webhook(self, webhook_data: dict):
    user_wallet = webhook_data.get('user_wallet')
    received_amount = webhook_data.get('amount', 0)
    
    if user_wallet in self.pending_payments:
        # Создаем вклад на полученную сумму
        transaction_id = self.create_user_transaction(
            user_id=user_id,
            amount=received_amount,  # Фактическая полученная сумма
            deposit_type=deposit_type,
            wallet_address=user_wallet,
            invoice_id=tracking_id
        )
```

### Регистрация ожидаемых платежей
```python
# Регистрируем ожидаемый платеж
self.pending_payments[wallet_address] = {
    'user_id': user_id,
    'deposit_type': deposit_type,
    'tracking_id': tracking_id,
    'payment_wallet': payment_wallet
}
```

## 🎯 Преимущества новой системы

1. **Автоматическая обработка** - не требуется ручная проверка платежей
2. **Мгновенное зачисление** - вклад создается сразу после получения платежа
3. **Точная сумма** - зачисляется именно та сумма, которую отправил пользователь
4. **Надежность** - webhook система более надежна, чем polling
5. **Масштабируемость** - может обрабатывать множество платежей одновременно
