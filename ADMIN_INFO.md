## Управление администраторами

### Добавить нового администратора

```bash
python3 add_admin.py add USER_ID
```

### Показать всех администраторов

```bash
python3 add_admin.py list
```

### Показать всех пользователей

```bash
python3 add_admin.py users
```

## Важно

- Только администратор имеет доступ к команде `/admin`
- Администратор может просматривать статистику всех пользователей
- Администратор может управлять депозитами и рефералами
- Для добавления новых админов используйте скрипт `add_admin.py`
