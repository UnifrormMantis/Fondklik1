## 🚀 ОБНОВЛЕНИЕ НА VPS:

### На VPS выполните:

```bash
cd /opt/fondklik/payment_bot

# Остановить бота
systemctl stop payment-bot.service

# Обновить код из GitHub
git pull

# Перезапустить бота
systemctl start payment-bot.service
sleep 3

# Проверить статус
systemctl status payment-bot.service --no-pager -l | head -10
```
