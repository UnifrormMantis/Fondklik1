## 🚀 API методы

### `create_payment(amount, currency, description, user_id)`
Создает новый платеж в системе.

**Параметры:**
- `amount` (float) - Сумма платежа
- `currency` (str) - Валюта (по умолчанию "USDT")
- `description` (str) - Описание платежа
- `user_id` (int) - ID пользователя

**Возвращает:**
```json
{
  "payment_id": "unique_payment_id",
  "payment_url": "https://payment-system.com/pay/...",
  "amount": 10.0,
  "currency": "USDT",
  "status": "pending"
}
```

### `check_payment_status(payment_id)`
Проверяет статус платежа.

**Параметры:**
- `payment_id` (str) - ID платежа

**Возвращает:**
- `"paid"` - Платеж оплачен
- `"pending"` - Ожидает оплаты
- `"failed"` - Платеж не удался
- `"error"` - Ошибка

### `get_payment_url(payment_id)`
Получает URL для оплаты.

**Параметры:**
- `payment_id` (str) - ID платежа

**Возвращает:**
- URL для оплаты или `None`

## 🔄 Поток платежа

1. **Создание платежа**
   ```python
   payment_data = await create_payment(10.0, "USDT", "Пополнение", user_id)
   ```

2. **Получение URL для оплаты**
   ```python
   payment_url = payment_data.get('payment_url')
   ```

3. **Проверка статуса**
   ```python
   status = await check_payment_status(payment_id)
   ```

4. **Обработка результата**
   - `"paid"` → Зачисление средств на баланс
   - `"failed"` → Отмена транзакции
   - `"pending"` → Продолжение ожидания
