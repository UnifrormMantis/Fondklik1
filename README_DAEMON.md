# 🤖 УПРАВЛЕНИЕ ТЕЛЕГРАМ БОТОМ В ФОНОВОМ РЕЖИМЕ

## 📋 ОБЗОР

Система управления ботом включает в себя:
- **Демон** - запуск бота в фоновом режиме
- **Мониторинг** - автоматический перезапуск при сбоях
- **Автозапуск** - запуск при загрузке системы
- **Управление** - удобные команды для контроля

## 🚀 БЫСТРЫЙ СТАРТ

### Основные команды:
```bash
# Запустить бота
./manage_bot.sh start

# Запустить с мониторингом (рекомендуется)
./manage_bot.sh monitor

# Проверить статус
./manage_bot.sh status

# Остановить бота
./manage_bot.sh stop
```

## 📁 ФАЙЛЫ СИСТЕМЫ

### Основные скрипты:
- `manage_bot.sh` - **Главный скрипт управления**
- `start_bot_daemon.sh` - Демон для запуска бота
- `bot_monitor.sh` - Мониторинг и автоперезапуск
- `setup_autostart.sh` - Настройка автозапуска

### Файлы данных:
- `bot_fondklik_correct.py` - Основной файл бота
- `bot_database.db` - База данных
- `bot_daemon.pid` - PID файл демона
- `bot_daemon.log` - Логи бота
- `bot_monitor.log` - Логи мониторинга

## 🛠️ КОМАНДЫ УПРАВЛЕНИЯ

### Основные операции:
```bash
./manage_bot.sh start          # Запустить бота
./manage_bot.sh stop           # Остановить бота
./manage_bot.sh restart        # Перезапустить бота
./manage_bot.sh status         # Показать статус
```

### Мониторинг:
```bash
./manage_bot.sh monitor        # Запустить мониторинг
./manage_bot.sh unmonitor      # Остановить мониторинг
```

### Автозапуск:
```bash
./manage_bot.sh autostart      # Установить автозапуск
./manage_bot.sh noautostart    # Удалить автозапуск
```

### Информация:
```bash
./manage_bot.sh logs           # Показать логи бота
./manage_bot.sh monitor-logs   # Показать логи мониторинга
./manage_bot.sh info           # Показать информацию о системе
./manage_bot.sh help           # Показать справку
```

## 🔍 МОНИТОРИНГ

### Функции мониторинга:
- ✅ **Проверка каждые 30 секунд** - статус бота
- ✅ **Автоматический перезапуск** - при остановке
- ✅ **Детекция зависания** - если нет активности >5 минут
- ✅ **Логирование** - все действия записываются

### Настройки мониторинга:
- **Интервал проверки**: 30 секунд
- **Таймаут зависания**: 5 минут
- **Лог файл**: `bot_monitor.log`

## 🚀 АВТОЗАПУСК

### Установка автозапуска:
```bash
./manage_bot.sh autostart
```

### Что происходит:
- Создается plist файл в `~/Library/LaunchAgents/`
- Бот запускается при загрузке системы
- Включается мониторинг для автоперезапуска

### Удаление автозапуска:
```bash
./manage_bot.sh noautostart
```

## ⚠️ УСТРАНЕНИЕ ПРОБЛЕМ

### Бот не запускается:
1. Проверьте права доступа: `chmod +x *.sh`
2. Проверьте Python: `python3 --version`
3. Проверьте файлы: `ls -la bot_fondklik_correct.py`
4. Посмотрите логи: `./manage_bot.sh logs`

### Бот зависает:
1. Мониторинг автоматически перезапустит
2. Проверьте логи: `./manage_bot.sh monitor-logs`
3. Ручной перезапуск: `./manage_bot.sh restart`

### Проблемы с автозапуском:
1. Проверьте статус: `./setup_autostart.sh status`
2. Переустановите: `./manage_bot.sh noautostart && ./manage_bot.sh autostart`
3. Проверьте логи: `tail -f launchd.log`

## 📈 ПРОИЗВОДИТЕЛЬНОСТЬ

### Мониторинг ресурсов:
- **CPU**: Минимальное использование
- **RAM**: ~50MB для бота + ~10MB для мониторинга
- **Диск**: Логи растут медленно (~1MB/день)

### Рекомендации:
- Используйте мониторинг для стабильной работы
- Регулярно проверяйте логи
- Установите автозапуск для серверов
