# 💰 СИСТЕМА ВЫПЛАТ ВКЛАДОВ

## 🎯 Описание системы

Система автоматически создает расписание выплат для каждого вклада:
- **Вклад**: 100% от суммы
- **Доход**: +10% от суммы  
- **Итого к возврату**: 110% от суммы
- **Срок**: 10 дней

## 🔧 Как работает

### 1. При пополнении баланса
- Пользователь вносит, например, 100 USDT
- Система автоматически создает 10 записей в `deposit_payments`
- Каждая запись = 110 USDT к возврату
- Расписание: ДЕНЬ 10, ДЕНЬ 9, ..., ДЕНЬ 1

### 2. В админ панели
- Кнопка **"💰 Выплата вкладов"**
- Показывает расписание по дням
- Группирует выплаты по датам
- **ДЕНЬ 1** - показывает все детали для выплаты

## 🗄️ Структура базы данных

### Таблица `deposit_payments`
```sql
CREATE TABLE deposit_payments (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,                    -- ID пользователя
    original_amount REAL,               -- Исходная сумма вклада
    return_amount REAL,                 -- Сумма к возврату (110%)
    payment_date DATE,                  -- Дата выплаты
    days_remaining INTEGER,             -- Дней до выплаты (10,9,8...1)
    status TEXT DEFAULT 'pending',      -- Статус (pending/paid)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 🚀 Использование

1. **Пользователь** вносит средства через бота
2. **Система** автоматически создает расписание выплат
3. **Админ** заходит в "Выплата вкладов"
4. **Видит расписание** по дням с деталями
5. **В последний день** - все конкретные данные для выплат
