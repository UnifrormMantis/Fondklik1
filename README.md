# 🤖 Telegram Bot - Пирамммида

## 🚀 Быстрый старт

### Запуск бота
```bash
./start_safe.sh
```

### Остановка бота
```bash
./stop_safe.sh
```

### Проверка статуса
```bash
./status.sh
```

## ✅ Что решено

- ✅ **Система блокировки** - невозможно запустить несколько ботов
- ✅ **Точный контроль** - отслеживается точное количество процессов
- ✅ **Автоматическая защита** - предотвращение конфликтов Conflict
- ✅ **Простое управление** - один скрипт для запуска/остановки

## 📊 Функции бота

- 💰 Пополнение баланса через USDT (CryptoBot)
- 👥 Многоуровневая реферальная система (6 уровней)
- 💸 Система вывода средств
- 🔧 Админ панель
- 📊 Статистика и транзакции

## 🔒 Безопасность

Система автоматически предотвращает запуск нескольких экземпляров бота, что исключает ошибки `telegram.error.Conflict`.

**Проблема с множественными ботами решена навсегда!** 🎉
