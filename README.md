# ФондКлик - Telegram Crypto Bot

Платформа для управления цифровыми активами с реферальной системой и автоматическими платежами.

## 🚀 Быстрый старт

### Локальный запуск

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Создание .env файла
cp .env.example .env

# 3. Добавьте токен бота в .env:
TELEGRAM_BOT_TOKEN=ваш_токен

# 4. Запуск бота
python3 bot_fondklik_correct.py
```

### Запуск на Railway/Render

1. Подключите репозиторий
2. Установите переменную окружения: `TELEGRAM_BOT_TOKEN`
3. Deploy автоматически запустит бот через `Procfile`

## 📁 Структура проекта

### Основные файлы
- `bot_fondklik_correct.py` - главный файл бота
- `payment_handlers.py` - обработчики платежей
- `payment_client.py` - клиент для Payment API
- `payment_config.py` - конфигурация платежей
- `database.py` - работа с базой данных
- `database_utils.py` - утилиты БД
- `simple_payment_api.py` - Payment API (для отдельного запуска)

### Конфигурация
- `Procfile` - запуск бота на Railway/Render
- `requirements.txt` - зависимости Python
- `runtime.txt` - версия Python
- `.env` - переменные окружения (создайте сами)

### Скрипты
- `start.sh` - запуск бота
- `status.sh` - проверка статуса

## 🔧 Функционал

- ✅ Telegram бот с реферальной системой
- ✅ Автоматическая проверка USDT платежей
- ✅ Многоуровневая реферальная система
- ✅ Админ-панель
- ✅ База данных SQLite
- ✅ Логирование

## ⚠️ Важно

**Бот и Payment API - это РАЗНЫЕ сервисы:**
- Бот работает сам по себе через `bot_fondklik_correct.py`
- Payment API (`simple_payment_api.py`) - отдельный сервис, НЕ запускается вместе с ботом

## 📝 Переменные окружения

Создайте файл `.env`:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
```
