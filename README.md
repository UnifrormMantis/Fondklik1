# 💰 ФондКлик - Telegram Investment Bot

Платформа для управления депозитами с фиксированной доходностью в USDT (TRC20).

## 🚀 Возможности

- 💸 Депозиты: 10 дней (8%) и 30 дней (30%)
- 👥 3-уровневая реферальная система
- 🔄 Автоматическая обработка платежей
- 👨‍💼 Админ-панель

## ⚙️ Технологии

- Python 3.11
- python-telegram-bot 21.10
- SQLite

## 🔧 Переменные окружения

```
TELEGRAM_BOT_TOKEN=ваш_токен
```
